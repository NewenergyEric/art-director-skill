# 用我们自己的制作过程学习判断

这些案例来自本项目已经生成、修改和检查的作品。此处整理教学记录，不重新生成“历史稿”，不把案例的画风、数字或观察结论变成新项目标准。案例均没有可据此认定为全套生产基线的主美批准。

| 要学习的动作 | 已填写案例 | 图像证据 |
|---|---|---|
| 把用途和保持项写成图解判断卡 | [微波炉：从单张造型到格内使用](microwave.md) | 修前、修后原文件与已保存的静态棋盘截图 |
| 同时设计家族关系和成员差异 | [潮灯小镇：四级灯具](lamp-family.md) | 四张独立素材、浅深背景与小尺寸检查图 |
| 定向修改并复查其他区域 | [赤砂补给站：风轮返修](depot-revision.md) | 实际修改前后图及修正指令摘要 |

三者分别讨论棋子使用、家族辨识和建筑局部编辑，完成度与材质也不同。灯具的金属表现、建筑细节不能作为微波炉或其他项目的复杂度要求。教学卡只说明指定判断，不能把整张图自动视为正向风格样板。

材料来源与未验证范围见各案例，复制文件的字节数和 SHA256 见 [provenance.json](provenance.json)。本目录仅收录本项目原创生成图与检查截图，不包含外部参考原件或完整制作档案。图像保持所取版本的原有字节，不作美化或重新裁切。

回到[通用方法](../visual-judgment.md)。成员实际使用的是本项目的规范、素材和决定；母 Skill 教学图不自动加入每个项目包。

# 多人视觉生产与组合设计

项目的核心单位是同一判断下的元素及其组合，不限游戏。品牌 UI、电商活动、宣传海报可以共享本工具的版本、身份、任务与评审机制；不要把游戏中的相机、棋格或引擎要求带到其他项目。

| 类别 | 持续保持的对象 | 可探索内容 | 组合时仍需检查 |
|---|---|---|---|
| 商品 `product` | 商品外观、包装、品牌标识和真实标签 | 有真实依据的视角、摆放与光影 | 是否真实代表商品、与场景比例是否自然、标签是否可读 |
| 图形 `graphic` | 品牌图形语言、活动识别、允许素材 | 装饰形状、节奏、组合关系 | 遮挡、透明边缘、与文案和商品争抢注意力 |
| 字体 `typography` | 真实字符串、文字层级、可用字体 | 项目允许的排版方案 | 实际字号、长文本、价格日期细则是否正确、裁切 |
| 版式 `layout` | 活动目标、品牌、安全区域与信息顺序 | 构图、留白、元素关系 | 所有元素版本、叠放、视觉层级、多渠道系列一致性 |
| 界面 `ui` | 组件状态、设计 token、交互及文字层级 | 内容、状态与布局适配 | 实际页面组合、长文本、操作区及响应尺寸 |
| 动效 `motion` | 源元素身份、信息传达顺序 | 允许的运动、节奏与过渡 | 实际回放、遮挡、阅读时间与平台输出 |

`project.domain` 描述业务场景，例如 `ecommerce`、`campaign-design`、`brand-ui`；它不自动添加一套通用审美。类别仅选择项目声明的部分。游戏仍用 [游戏美术](game-art.md)，同一方法也能覆盖场景和建筑效果图，但不能把渲染图片当作施工或工程文件。

## 主美和成员分别做什么

总监拿现有品牌规范、批准样稿、商品原图、团队反馈给 Agent。Agent 按[总监工作流](director-workflow.md)先整理定位、视觉语言、组件/模板家族、样板和渠道交付初稿，再把需要取舍的内容交总监评审。成员说本次任务，不重新定义整个品牌。没有完整原图也可以做标明缺口的提案，不能由低清参考伪造正式商品母版。

成员各自制作的元素记录资产 ID、负责人、版本和参考。合成设计师接收的是可追溯元素及真实文字；外包沿用同一项目基线。拆分 skill 时用共享入口调用各类模块，不为海报、横幅、UI 各复制一份彼此会漂移的品牌规范。

## 编译组合任务

运行层请求以 `layout` 或 `ui` 为主类别，用可选 `components` 显式绑定组成对象，例如：

```json
"components": [
  {"category": "product", "subject": "主商品"},
  {"category": "graphic", "subject": null},
  {"category": "typography", "subject": null}
]
```

上例用于尚未定义家族的项目；若类别已有家族，Agent 在主请求和相关组件中另填 `family`，引用当前包实际 ID。家族可代表 UI 组件、活动卡片、社媒模板或一个元素系列。其状态、变体、替换槽位和组合关系沿用家族要求，而非仅继承一张风格图。

这段输入由 Agent 从需求推导并核对，不要求成员填写。运行层会对同一冻结包编译各类 brief，合并规则与引用，保留各组件身份。它没有自动识别画面里漏填的对象，Agent 仍须读实际任务和组合画面。一次引用多个组件不是已具备这些组件文件，也不证明已获得视觉一致性。

新任务先明确是探索、制作还是交付。参考图生成模型用实际图像输入；品牌标识、精确文字与价格优先使用真实素材和可编辑排版。不得凭空填写活动日期、折扣或商品属性。不同工具间交接任务书、输入图、规则、原始结果和未检查项。

## 正式交付链

1. 概念提案：回答构图与方向是否值得推进。
2. 单件素材：分别导出所需主体、装饰和图形；不要只交一张扁平综合图。
3. 编辑和排版：在 PS、Figma 或实际工具中确认画布、图层、文字、裁切、色彩与导出。按需求交付可编辑源；没有打开源文件就不能确认图层可用。
4. 组合检查：核对主体身份、项目风格、信息顺序、真实文字、版本及实际显示尺寸。单件合格不代表组合合格。
5. 渠道交付：根据项目既定要求检查真实投放或界面环境，保留文件、检查证据和负责人。未做的检查保持 unknown。

多渠道任务同时管理共同母版与变体：保留内容优先级、品牌/商品身份和家族识别；按具体渠道重排留白、裁切、文字与行动入口。先验证一个代表性组合及风险较高的变体，再批量展开。社媒系列、新促销和活动海报沿用已定模板中的开放槽位，不重新猜每张图的结构，也不把不同尺寸机械拉伸视为适配完成。

已确认的规格复用；没给的参数按当前阶段说明缺口，不把流程模板变成每次长表单问答。超出现有规范的创意可保留并交总监权衡收益、返工影响与上线时间，再决定升版、局部试用或以后采用。

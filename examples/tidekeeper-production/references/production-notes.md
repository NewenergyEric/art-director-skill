# 0.3 连续场景试作

沿用0.2.1，新增昼夜场景、修缮/举灯姿势和补给船，并在组合检查后重做待修状态，共五次实际图像生成。运行时实现修缮扬尘、窗灯、海面反光、尾迹、物品反馈与奖励。所有示例仍是候选。motion 类别记录事件、时长、接触点、层级与减少动态要求，依赖归入同一生产计划。

源画布900×1600，运行画布390×844；角色为叙事插演，非正式地图转面动画。新夜景保持主要地标但仍有细节差异，不作为无缝引擎替换通过。母规范、制作计划和场景配方各司其职，不复制审美标准。

Compositor只导出图片图层。界面文字和事件源码保留在HTML/JS，动效不是原生Compositor动画。原生Mac打开、真实主美审阅、手机和引擎验收待进行。

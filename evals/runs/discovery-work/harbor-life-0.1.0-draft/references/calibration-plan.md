# 下一步校准样板任务书（提案，尚未制作）

项目：港口生活美术意图讨论稿；版本 0.1.0；阶段：概念方向讨论。

目标：检验读者是否能同时感到“古老、温暖、有人维护”，并看清角色正在做什么。样板供选择视觉表达，不是可导入引擎的生产资产。

建议先回答 STYLE.md 中 P0-1 和 P0-2，再做一个组合样板。可选题材是一小段仍在使用的码头或沿港生活入口，一位居民正在照料常用器物，画面旁附一小块可编辑的交互文字。人物职业、港口文化与器物类型随世界设定选择；这只是统一测试任务，不是已批准的关卡设定。

读取类别：character、environment、prop、ui 及 global 全局规则。所有具体规则仍为 proposed，不要把草案写成既定生产标准；没有已确认角色身份，因此不延伸设计角色背面或跨镜头身份规范。

## 固定与可变

- 本次固定目标：同一个生活动作、同一处小空间、相同信息内容，便于比较。
- 可以试验：年代感的强弱、修补痕迹的表达、线条与材质概括程度、局部色温关系。
- 若需要比较 2D/3D，用同一游戏尺度和动作验证，不把精美概念插画与灰盒模型直接当作风格优劣比较。
- 仅出现真实分歧时追加一个对照，且一次只改变一个关键变量；没有分歧就不增加方案数量。

## 输入、输出与未定条件

目前只有文字 context 参考 USER-BRIEF；它不能作为图像 style 或 identity 输入。若后续补图，逐张注明 style、identity、composition 或 context 角色、来源与可用权限，再决定是否纳入规则。

建议输出：一张组合样板；可编辑的角色/场景/道具/UI 分层或对应工作文件（格式随制作链确定）；一份短注释，把可见部位与规则 ID 对应；一份 pass/fail/unknown 评审记录。概念画布、实际游戏视角、目标屏幕尺度、字体及字符范围待决定后填写，不在当前阶段编造尺寸。

## 验收提问

1. 看见哪些具体部位，让你认为这里已使用很久？
2. 哪些部位显示有人持续照料，而不是刚刚遭到破坏或被弃置？
3. 哪个行为或空间关系让你感到愿意接近或停留？移除暖色滤镜后还能成立吗？
4. 角色的动作、器物的用途以及下一步可交互对象是否清楚？
5. 放到候选游戏视角与显示尺度后，上述证据还看得见吗？尚无尺度时此项写 unknown。

记录接受/拒绝的具体差异及原因，由待指定的美术决策负责人确认后再更新 JSON。若只是本张图的问题，修图；若是类别共性，修改对应规则；不要因一张图的反馈改全项目规则。

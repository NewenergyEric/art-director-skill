## 意图

用一个有历史、让人感到温暖、持续有人认真维护的港口承载日常生活。题材与目标感受来自用户；以下视觉机制是讨论提案，未经样板确认。

- 古老：传达时间积累。以使用痕迹及新旧并存来表达是候选机制，并未选定历史年代。
- 温暖：传达可亲近、愿意停留的生活感。人和物的关系、空间安排与局部光色是候选机制，不等于全画面暖色。
- 仍有人认真维护：传达持续照料。维护痕迹应具有用途与逻辑，是本稿的候选表达。

### 避免

- 候选排除项：将古老统一表现为坍塌、废弃或无差别重锈；特殊区域例外待世界设定确认。
- 候选排除项：用整幅黄褐滤镜或每处发光替代生活温度。
- 候选排除项：随机摆满海事符号和杂物，遮蔽人物活动与物件用途。
- 未选定：写实/风格化程度、历史或幻想设定、具体文化、时代、镜头、色板、字体、2D/3D。

## 规则

### INTENT-01 · must · proposed

适用：global

候选代表样板应同时提供时间积累、生活温度与持续维护的可观察证据；评审者应能指出具体部位或行为。

原因：把用户的三个感受放在同一画面中校准，避免只达成其中一个。

允许变化：

- 不要求每个小资产独立承担全部情绪；组合样板承担整体检验。
- 实现机制与风格化程度可变；这是候选验收方式，不是已批准规则。

依据：USER-BRIEF
检查方式：human

### ENV-01 · should · proposed

适用：environment

长期使用的部位可保留磨耗、褪色或材质变化，同时在关键使用部位安排有因果的维护痕迹。

原因：让古老与认真维护共存；维护针对实际使用需求。

允许变化：

- 修补、替换、清洁路径、重新固定都可表达维护，不强制全部同时出现。
- 不同材质与区域采用不同程度；不预定材质种类或精确磨损比例。

依据：USER-BRIEF
检查方式：visual

### ENV-02 · should · proposed

适用：environment

温暖感可由可停留的空间、照料行为与局部光色关系共同表达；以生活关系为评审线索。

原因：暖色本身不足以证明港口仍有人生活。

允许变化：

- 允许阴天、冷色水面、夜晚和危险区域；如何服务主情绪需在具体场景说明。
- 不强制每个入口挂灯、不预定夕阳、不指定全局色温。

依据：USER-BRIEF
检查方式：visual

### ENV-03 · should · proposed

适用：environment

生活物件的安排应能解释人如何经过、工作、收纳和休息，保留可读的活动路径。

原因：让港口成为被实际使用的生活空间，并为后续玩法留出空间。

允许变化：

- 疏密、建筑语言和物件类别随设定变化。
- 繁忙区域可以拥挤，但需要说明玩家应注意什么；具体导航方案待玩法确认。

依据：USER-BRIEF
检查方式：visual

### CHAR-01 · should · proposed

适用：character

人物的旧衣物或装备若出现维护痕迹，应与其使用方式关联，并保留动作和身份线索的可读性。

原因：把认真生活的感觉延伸到人，同时避免把古老误写成人人贫困或疲惫。

允许变化：

- 允许干净衣物、新部件及不同生活状况；不要求每个人补丁遍身。
- 身材比例、物种、职业、服装年代、轮廓与身份尚未确定。

依据：USER-BRIEF
检查方式：visual

### PROP-01 · should · proposed

适用：prop

常用器物应能解释用途与握持/摆放关系；旧感和修理优先出现在有使用原因的部位。

原因：让物件表现长期被使用和珍惜，而不是装饰性的损坏。

允许变化：

- 可有新旧部件并置或整件较新器物；不规定修补手法。
- 纯装饰、废弃物及损坏任务道具可例外，需在任务书说明用途。

依据：USER-BRIEF
检查方式：visual

### UI-01 · must · proposed

适用：ui

关键文字、状态与操作提示应在实际显示尺度中被清楚识别；装饰痕迹不应损害信息。

原因：港口的历史气质需要与玩家获取信息的任务相容。

允许变化：

- 可在标题、边框和图标探索材质或工艺感；正文处理单独评审。
- 字体家族、字号、字符覆盖、输入方式和数值对比度目标均待定。

依据：USER-BRIEF
检查方式：visual

### READ-01 · must · proposed

适用：global

在确定游戏视角和目标显示尺度后，将人物、场景、道具和实际 UI 内容一起检查；未确定前把游戏可读性标为未检查。

原因：局部精致的设计不一定能在游戏中被看见，尺度决定细节投入。

允许变化：

- 具体轮廓、亮度、动作、空间或提示方法由玩法和媒介选择。
- 不预设等距视角、不预设背景低饱和、不预设高亮颜色。

依据：USER-BRIEF
检查方式：human

### VARIATION-01 · should · proposed

适用：environment, character, prop

不同区域和资产可在新旧程度、照料方式与情绪上变化，但应说明与港口生活主意图的联系。

原因：为真实生活的差异留空间，避免所有物件拥有同一种旧化贴图或修补套路。

允许变化：

- 危险、荒废、富裕、贫困等设定均未确认；不得凭规则擅自新增剧情事实。
- 是否设置偏离主情绪的区域，由后续世界设定决定。

依据：USER-BRIEF
检查方式：visual

## 待决问题

- P0-1｜玩法负责人：玩家在港口最常做什么，最需要看清什么？例如经营安排、与居民交往、近距离探索或动作操作。影响镜头、焦点和细节分配，先回答这一题。
- P0-2｜美术与玩法负责人：玩家通常从多远观察，预期什么设备与输入方式？先描述体验即可，不必立刻二选一 2D/3D；据此提出可比较的媒介试验与实际阅读尺度。
- P1-1｜世界设定与美术负责人：港口有无特定时代、地域文化、技术水平或幻想规则？哪些元素必须出现或绝不能出现？决定建筑、服装、工艺与器物的可信范围。
- P1-2｜美术决策负责人：三种感受发生冲突时如何取舍，允许多大范围的冷清、破败或危险？希望温暖更接近日常平实、热闹亲密还是童话感？这是讨论选项，不是本稿假设。
- P1-3｜美术与制作负责人：偏好怎样的形状概括、材质细节与表现手法，团队哪些制作能力最可持续？先用文字排除不喜欢的特征或稍后提供少量参考，再按共同样板比较；不要求先搜齐参考图。
- P2｜制片与美术负责人：谁负责拍板首个样板，什么时候需要它，首轮能投入多少制作时间？平台、语言与后续资产规格在进入生产前补齐，不阻塞当前意图讨论。

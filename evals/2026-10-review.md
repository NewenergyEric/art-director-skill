# 2026-10 可用性复核

本轮按 Darwin Skill 2.1 的九维量表复查公开入口，并保留原有 [v0.2 Darwin 审查](darwin-audit-v0.2.md)。已有四个核心 prompt 的结果仍有效；本轮新增人类/Agent 手册、GitHub 参考扫描和跨岗位说明。

## 结果

| 项目 | 结果 |
|---|---|
| Agent 入口 | `SKILL.md`、项目包 `PROJECT.md`、版本指纹和引用路径可定位 |
| 人类入口 | 30 秒安装、主美工作台、70 秒视频、项目包与成员示例均可访问 |
| 确定性测试 | 既有 108 项测试与既有流程证据；本轮未改核心脚本 |
| 反例与失败路径 | 手册新增资料不足、参考冲突、首件失败、版本漂移、无图像访问和越权覆盖分支 |
| runtime-neutrality | Skill 入口不绑定单一 Agent 厂商；README 的生态列表只描述安装兼容性 |

## 仍需独立审查

本报告是同一维护者的结构和流程复核，不是独立模型的盲测。下一轮应让独立模型使用 `evals/darwin-test-prompts.json` 复跑，并由真实团队记录首过率、返工次数、交接时间和视觉批准质量。

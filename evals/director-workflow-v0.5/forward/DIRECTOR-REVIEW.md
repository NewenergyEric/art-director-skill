你已经有共同视觉起点。先统一轮廓、形体、颜色用途、细节密度和信息顺序，再让各类用家族与状态连接。建议先评角色入街区、盆栽等级、按钮状态三个小样；确认后再做物件卡和宣传组合。

## 要一起统一的判断

| 对象 | 当前建议 | 留给成员变化 | 验证点 |
|---|---|---|---|
| 大中小形 · G-02 | 以完整的大轮廓、少量内部结构和干净色块建立识别；先大形再补生活细节。 | 场景允许比 UI 更多细节；缩小或叠放时先删不承担身份/功能的细节。 | visual；仍待首件 |
| 轮廓 · G-03 | 候选共同轮廓为深蓝偏黑、圆转角；按实际显示类别校准视觉粗细，不直接统一所有资产的像素线宽。 | 场景远景可弱化轮廓；UI 状态边界仍需清晰。 | visual；仍待首件 |
| 色彩角色 · G-04 | 先统一色彩角色：暖浅底承托，薄荷作成长/进度，珊瑚作主行动，金黄作奖励；各状态还需文字或形状提示。 | 同世界局部材质色可以扩展；不得仅用颜色区分状态。 | visual；仍待首件 |
| 材质/细节 · G-05 | 材质以一处主明暗和少量高光交代体积；避免新增照片质感、金属反射或大量微纹理。 | 街区砖墙可作节奏纹理；交互区与小图标需减密。 | visual；仍待首件 |
| 使用场景 · G-06 | 最终认可前同时看单件、相邻物件和真实使用背景；未知屏幕条件只允许相对尺度草图评审。 | 本阶段可用无固定像素要求的并排图和位置草图。 | human；仍待首件 |
| 字体与文字 · TYPE-01 | 中文、数字、日期和操作文案使用可编辑文字；字体家族、字重、授权和回退未确定前不写入字体 token。 | 首样可用带“临时排版”标记的系统字体作结构测量，不能当正式字体批准。 | technical；仍待首件 |

每条规则完整的理由、适用类别、强度、可变范围和证据都在 [STYLE.md](review-pack/STYLE.md)。must/should 表达候选强度，不表示主美已经确认。

## 五类怎么接上

| 交接 | 传递内容 | 组合负责人要看什么 |
|---|---|---|
| 居民 → 街区 | 同一身份、姿势重心、落点、动作占用范围 | 门口比例、接地、植物遮挡、可通行空间 |
| 合成物件 → UI 卡片 | 家族/等级、本体完整轮廓、状态覆盖层 | 等级结构不被角标盖住；名字和条件有位置 |
| 世界物件 → 街区 | 同家族核心形状、落地点、角色使用方向 | 阴影与场景一致；图标展示阴影不能直接复用 |
| 居民/街区/物件/UI → 宣传 | 版本、身份、可编辑内容区、真实活动信息 | 主视觉与标题不竞争；同世界、适配渠道、内容真实 |

候选分工：主美 A 负责判断和集成验收；B 角色与物件；C 街区；D UI 与宣传。当前没有实际指派或排期承诺。

## 小样与首件顺序

| 顺序 | 要回答的事 | 何时才算有证据 |
|---|---|---|
| S1 居民 × 街角 × 陈设首样 | 先决定视觉层级与尺度关系，并比较保留原场景细节/略减纹理的取舍。主美负责选择，B/C 制作；尚未制作。 | 候选居民 A 与门口、花盆同画面；单件轮廓和组合接地各有观察图。；先用相对比例确认角色与门口关系；真实相机/屏幕确定后必须重查，不宣称当前已满足游戏尺度。 |
| S2 盆栽三阶段视觉链 | 验证同一容器/生长轴与阶段差异；B 制作、主美与玩法负责人决定链是否采用。 | L1 芽苗、L2 叶丛、L3 开花并排；隐藏名字/颜色仍能描述结构差异。；同一虚拟容器范围下比较主体留白与轮廓，实际显示大小未知时不声称小尺寸通过。 |
| S3 主按钮状态与文字首件 | 验证从概念到可编辑组件的制作方法；D 制作，主美评视觉、产品定触发逻辑。 | 展示 normal/pressed/disabled/loading/complete；同一标签和轮廓可以跟踪。；有真实短/长中文、数字和禁用原因后排版；未提供前只交占位结构。 |
| S4 物件 × 卡片 × 角标组合 | 在 S2/S3 的选择后确认跨类别接口；B 提本体、D 合成、主美审使用层级。 | L1/L2/L3 与 normal/selected/locked/max_level 的关系可追踪；不需要穷举所有排列，先覆盖最密/最长/最易混淆一例。；角标不盖住等级结构，卡片文字不挤压本体，合成条件来源明确。 |
| S5 活动宣传结构与裁切 | 在前述选择和真实活动表齐备后验证游戏资产到宣传的转换；D 组合，B/C 提源，主美审信息。 | 标题、主视觉、时间条件、行动入口、细则先后可读；本轮只安排占位结构。；按届时确认的一横一竖或真实渠道重排，不提前写假尺寸。 |

S1/S2/S3 可在关键输入到位后分别做；S4 依赖物件与 UI 的选择，S5 依赖前述资产、活动表与渠道。完整首件源文件、检查范围和未覆盖项在 [样板计划](review-pack/guides/00-index.md) 与 [交付验收](review-pack/guides/03-delivery-review.md)。

## 留待主美的下一步选择

1. 主美下一步选择 1〔先评 S1〕：建议延续现板轮廓/暖色，但在操作区减场景细节；选择保留原密度或简化一档。影响街区工时与角色/UI 焦点，不需要现在填色值。
2. 主美下一步选择 2〔先于 S2 实作〕：是否用盆栽芽苗→叶丛→开花作视觉测试家族；若玩法不合适，指定一条真实日常物件链。正式等级数与合成配方由玩法资料提供。
3. 主美下一步选择 3〔先于 S1 游戏尺度 / S3〕：与产品确定首个使用场景、2D/3D/混合、实际相机、屏幕/方向和可操作区域；本轮没有代选手机或等距。
4. 主美下一步选择 4〔先于 S3 首件〕：提供真实短/长中文与数字样例，选一套可用字体及来源/许可；建议先看读字和状态，再定装饰字气质。
5. 主美下一步选择 5〔开始实际制作前〕：确认 A/B/C/D 实际分工、第一轮可用工时/费用、使用工具与是否允许外部生成。当前 max_candidates=1 仅本地任务准备参数，不构成生成预算授权。
6. 活动负责人下一步输入〔S5 前〕：真实活动表与渠道；可先评结构，但没有这些资料不做正式宣传文案/导出。
7. 后续启用：对所选规则和样板逐项记录真实决定与范围；源草稿回写重建，发布前 release 检查；不要把本次 draft 或 ZIP 当已批准生产标准。

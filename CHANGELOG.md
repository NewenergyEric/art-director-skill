# Changelog

## 0.5.1 — 2026-10-10

- Reframed the product around the director-led workflow: project positioning, shared visual language, category and component families, representative exemplars, first-piece gates, delivery rules, and a package the team can call directly.
- Added five derived project guides, portable member workspaces, frozen task baselines, family-aware production briefs, multi-component composition tasks, batch evidence checks, and explicit specification upgrades.
- Added complete game and campaign examples covering characters, environments, tiles, props, HUD, motion, products, graphics, typography, layouts, and multi-channel delivery.
- Replaced the default web demo with the director workbench while retaining single-task and team-production demonstrations as supporting examples.
- Expanded the deterministic suite to 108 tests and added independently executed director-to-member workflow evidence.
- Updated GitHub Pages to publish the linked examples and source evidence with the workbench, refreshed CI dependencies, and removed obsolete public artifacts containing local paths or early private-trial wording.

## 0.2.0 — 2026-10-10

- Rebuilt the Skill entrypoint against the Darwin nine-dimension rubric, adding explicit first-piece and baseline-release checkpoints, recovery branches, and an anti-pattern blacklist.
- Added three representative Darwin evaluation prompts, a paired before/after audit, and game-production research grounded in official Unity and Unreal documentation.
- Rewrote the bilingual README around art-director and team outcomes, with capability-specific visual evidence, a five-minute path, explicit limitations, and MIT licensing.
- Replaced the slide-like hero with a 30-second bilingual Remotion film built around one continuous production canvas, four visual languages, seven asset templates, four production lanes, and a moving review lens.
- Added original production boards covering character, item, UI, skill/VFX, match, puzzle, tabletop, pseudo-3D, American-comic, traditional, and painterly-card systems.
- Extended the team workflow to UI systems, e-commerce campaigns, promotional posters, social templates, and multi-size channel delivery.
- Added a reproducible MP4/GIF pipeline with local original sound design, release clips, reduced-motion stills, and browser detection.
- Expanded the security statement to cover every network, credential, subprocess, write, and deletion boundary; enabled CodeQL, Dependabot, and private vulnerability reporting.

## 0.1.0 — 2026-10-09

- Added the Art Director mother skill for turning visual intent, references, and review feedback into project-specific style packs.
- Added the standard-library `style_pack.py` CLI for validation, rendering, scoped briefs, immutable builds, integrity checks, archives, and diffs.
- Added `pilot.py` for source-material inventory, optional pixel-level image checks, and separated AI-proxy / human-team pilot summaries.
- Added game-art guidance for characters, environments, props, and typography/UI.
- Added a production-at-scale method for casual, match-3, live-ops, and outsourced asset batches.
- Added templates for style packs, entity dossiers, production tasks, review reports, delivery records, change proposals, and pilot records.
- Added the fictional Moss Harbor draft, deterministic tests, independent usage exercises, and validation reports.
- Added a bilingual Remotion hero film centred on the art director, the team, and high-volume game-asset production.
- Added the six layout patterns used by the workflow page and repository visuals.

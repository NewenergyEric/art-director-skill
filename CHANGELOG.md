# Changelog

## 0.1.0 — 2026-10-09

- Added the Art Director mother skill for turning visual intent, references, and review feedback into project-specific style packs.
- Added the standard-library `style_pack.py` CLI for validation, rendering, scoped briefs, immutable builds, integrity checks, archives, and diffs.
- Added `pilot.py` for source-material inventory, optional pixel-level image checks, and separated AI-proxy / human-team pilot summaries.
- Added game-art guidance for characters, environments, props, and typography/UI.
- Added a production-at-scale method for casual, match-3, live-ops, and outsourced asset batches.
- Added templates for style packs, entity dossiers, production tasks, review reports, delivery records, change proposals, and pilot records.
- Added the fictional Moss Harbor draft, deterministic tests, independent usage exercises, and validation reports.
- Added a bilingual Remotion hero film centred on the art director, the team, and high-volume game-asset production.
- Added the six layout patterns used by the workflow page and repository visuals.

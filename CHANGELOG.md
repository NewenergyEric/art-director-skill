- Rebuilt the Skill entrypoint against the Darwin nine-dimension rubric, adding explicit first-piece and baseline-release checkpoints, recovery branches, and an anti-pattern blacklist.

- Rewrote the bilingual README around art-director and team outcomes, with capability-specific visual evidence, a five-minute path, explicit limitations, and MIT licensing.
- Replaced the slide-like hero with a 30-second bilingual Remotion film built around one continuous production canvas, four visual languages, seven asset templates, four production lanes, and a moving review lens.
- Added original production boards covering character, item, UI, skill/VFX, match, puzzle, tabletop, pseudo-3D, American-comic, traditional, and painterly-card systems.
- Extended the team workflow to UI systems, e-commerce campaigns, promotional posters, social templates, and multi-size channel delivery.
- Added a reproducible MP4/GIF pipeline with local original sound design, release clips, reduced-motion stills, and browser detection.
- Expanded the security statement to cover every network, credential, subprocess, write, and deletion boundary; enabled CodeQL, Dependabot, and private vulnerability reporting.

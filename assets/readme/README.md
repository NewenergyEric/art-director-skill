# README motion source

The hero film is built in Remotion from original fictional studio and casual-game artwork. Chinese and English compositions share the same visual direction and timing.

```sh
npm install
npm run motion:studio
npm run motion:render
```

The source lives in `motion/src/`. Raster artwork lives in `motion/public/studio/`, `motion/public/styles/`, and `motion/public/maple-corner/`. The public composition canvas is 1280 × 720; the spatial product film is 18 seconds at 30 frames per second.

Each README embeds one six-second `depth-preview` GIF (800 × 450, 20 fps), with a matching JPG for reduced motion. The GIF and 18-second web film share the same source composition, core claim, type system, colour system and spatial movement. Web videos use 30 fps H.264 with faststart metadata and manual playback.

The sequence has three beats: start with work the director trusts, build professional judgement into project memory, and deliver from the same version. Motion should make that relationship easier to understand through continuous depth, rather than page-cut transitions.

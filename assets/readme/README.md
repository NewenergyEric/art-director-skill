# README motion source

The hero film is built in Remotion from original fictional studio and casual-game artwork. Chinese and English compositions share the same visual direction and timing.

```sh
npm install
npm run motion:studio
npm run motion:render
```

The source lives in `motion/src/`. Raster artwork lives in `motion/public/studio/`, `motion/public/styles/`, and `motion/public/maple-corner/`. The composition canvas is 1280 × 720; the published full film is 1100 × 618, 30 frames per second, and 70 seconds long.

Render the MP4 masters first. Each README embeds one twelve-second `quick-preview` GIF (1100 × 618, 20 fps), with a matching JPG for reduced motion. It links to the full introduction and four clips on the site. Web videos use 30 fps H.264, faststart metadata and manual playback for the longer sequences. Full-film stills remain available separately.

The sequence has six beats: meet the team at the review table, see the production wall, move through four visual languages as tangible outputs, switch among seven production templates, follow work across team lanes, and carry reviewed judgement into the next version. Motion should make the work easier to understand. Keep people and real production material at the centre of the film.

# README film assets

Each README embeds one 24-second `depth-preview` GIF (800 × 450, 20 fps during motion), with a matching static JPG for reduced motion. The website plays the same story as a 1280 × 720 / 30 fps H.264 MP4, on demand.

The story shows references becoming rules and samples, a project Skill reaching teammates, a button task using those rules, and a visible correction after review. It uses original candidate artwork and a clearly labeled illustrative task. The production card transforms into the review card so the correction stays connected to its context.

Source: `motion/src/DepthShowcase.tsx`. Build and media budget instructions: [motion/README.md](../../motion/README.md). Current checksums: [manifest](../../docs/assets/motion/manifest.json).

# README film assets

Each README embeds one 24-second `depth-preview` GIF (800 × 450, 20 fps during motion), with a matching static JPG for reduced motion. The website plays the same story as a 1280 × 720 / 30 fps H.264 MP4, on demand.

The story follows references and samples into a shared project pack, assigned components, an in-game assembly check and a continuous scene with a six-pose repair study. It closes on “One team, one visual memory.” The original artwork and animation remain candidates; the film's six poses are separate from the eight-pose Tidekeeper playable sample.

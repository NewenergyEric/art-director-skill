# Presentation fonts

- **Bree Serif Regular**, TypeTogether. Original TTF, unmodified. Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/breeserif). SHA-256 `fd080582d70112ef479ba4ddd72407f9a4fcbcec4caa7d29de259b13eeb5f431`. License: `BreeSerif-OFL.txt`.
- **Harbor Brush Display**, a web subset of LXGW WenKai Medium. The internal family/PostScript names are changed for the subset; original glyph drawings are retained. Source: [LXGW WenKai](https://github.com/lxgw/LxgwWenKai), `fonts/TTF/LXGWWenKai-Medium.ttf`, source SHA-256 `cd665aabdecd4c025d30307efaebee02e604b6f768885b28297bc22a8cb379e03`. Subset covers current film and website text, with WOFF2 encoding. License: `WenKai-OFL.txt`.
- **Noto Sans SC**, the existing shared body/UI variable subset. License: `OFL.txt`.

Display fonts are selected for this fictional harbor's warm, handcrafted tone. They are not universal defaults for other game genres. English uses the original regular weight; Chinese uses medium. No synthetic italic or generic heavy outline is applied.

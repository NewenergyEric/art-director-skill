# Nocturnal Restitution: a distinct style, down to the last component

**A character, an object and an interface should all feel at home in the same world.**

This gothic point-and-click adventure was developed through the Art Director workflow. Its visual memory combines burgundy cloth, worn leather, aged brass, cool stone and restrained painted light. The direction covers character identity, scene scale, material response and UI components, then carries those decisions into new work.

## Puzzles and interfaces belong to the world, too

![Actual English optics puzzle, using the calcite assembly in the interactive close-up.](assets/nocturnal-restitution/optics-en.webp)

<img src="assets/nocturnal-restitution/calcite-lens.webp" width="220" alt="The calcite and brass assembly used at the center of the puzzle above">

The calcite assembly carries the gallery's metal, stone and lighting relationships into a puzzle close-up. The scene, collectible and interactive panel have different jobs while still reading as parts of one game.

![The actual English Conservator's Roll: material family, assembly area and installed states.](assets/nocturnal-restitution/workshop-en.webp)

Tools and materials retain distinct surfaces. Panels, tabs and interaction states share dark grounds, fine brass lines and paper-colored text. Component requirements cover function and state, followed by inspection in the actual interface.

## What this case demonstrates

| Scope | Shared constraints | Visible comparison |
|---|---|---|
| Character | Identity, costume, silhouette and detail scale | The same lead character inside the gallery |
| Props | Distinct aged brass, stone and leather | Source objects alongside their inventory and puzzle use |
| UI | Painted materials, color relationships and hierarchy | Leather inventory, watch, workshop and mechanism panel |
| Composition | Scene scale, lighting and interaction state | Components combined in actual gameplay |

This is a direction → continuation → in-context review case. A promotional image alone would not establish that chain.

# 人类使用说明 · Art Director

## 这份 Skill 解决什么问题

把美术总监的判断建立成团队可以读、可以交接、可以版本化的项目规范。它锁住视觉底线，同时把经过授权的动作、姿势、服装、构图和渠道变化留给创意探索。

## 30 秒开始

1. 安装：

   ```sh
   npx skills add https://github.com/NewenergyEric/art-director-skill
   ```

2. 把已有作品、参考图、批注和项目目标交给 Agent，并说：

   > 使用 `$art-director`，先把资料整理成可评审的定位和视觉规范，再带我补齐组件家族、代表样板、交付与验收，最后生成可分发的项目包。

3. 审核事实、候选建议、待定问题和样板计划；确认后再 `build --release`。
4. 把项目包分给成员，成员使用项目包中的 `SKILL.md` 与固定版本开始任务。

## 你需要提供

项目定位、已有作品与参考、反例、目标平台、组件/资产类别、身份底线、可变项、技术规格和谁有批准权。缺少图像或真实规格时，Agent 应标为待补，不替你猜。

## 你会得到

五份同源手册、`style-pack.json` 唯一事实源、项目 `SKILL.md`、参考清单、任务卡、批次检查和内容指纹。项目包可以压缩分发；正式 release 仍需要真实批准依据和必要样板。

## 关键边界

- Skill 不替你判断美丑，不把概念图宣布为生产资产，也不自动批准规范。
- 工具在本地运行，不自动上传项目材料；生成/编辑工具按宿主能力和用户授权使用。
- 草案、候选和批准版本分开；更新规范会产生新版本，旧任务继续使用冻结快照。
- 真实艺术质量、引擎/渠道集成和团队效率仍需要真人批次验证。

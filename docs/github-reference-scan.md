# GitHub 同类参考与本仓库取舍

本轮检索的公开项目帮助校准岗位描述和验证入口：

- [game-art-director](https://github.com/roohe/agentic-super-skills/blob/master/skills_library/game-art-director/SKILL.md)：把视觉总监写成有触发词、升级路径、反例和输出格式的岗位；本仓库吸收其“视觉宪章、升级对象和跨部门升级”表达，同时保留主美逐步建项和项目包版本模型。
- [ai-game-art-pipeline-skill](https://github.com/ybuild-ai/ai-game-art-pipeline-skill)：按运行时任务组织资产 QA；本仓库吸收其“任务 → 技术检查 → 交付”结构，但不把生图或清理能力写成主美判断的替代品。
- [GameStudio art-bible](https://github.com/bullish0x/GameStudio/tree/main/.agents/skills/art-bible)：强调形状语言、色彩、氛围、角色、环境、UI 和反例库；本仓库将这些判断放进项目包的类别/家族/实体层，并保留证据状态。
- [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)：把“检查后才能称为可交付”写进资产技能；本仓库沿用技术检查、视觉判断和未检查项分离。

这些项目是方法参考，不是本仓库的依赖，也不证明它们与本项目的视觉标准相同。真实案例、真实首件和真实团队效率仍需后续补入。

# Marketing and design review · v0.2

## Review brief

Audience: art directors, design leads, senior designers, technical artists, studio owners, and the internal or external teams they direct across games and other multi-person visual production.

Decision the page should enable: understand within one scroll that Art Director preserves project judgement, turns it into discipline-specific production tasks, and carries confirmed decisions into later rounds.

### Copy decisions

- Kept **“一套方向，要带得动整支团队 / One direction has to move an entire team.”** because it connects the director's responsibility to team scale in one line.
- Kept **“先看一小批。确认了，再把产量放大 / Review a small batch. Align. Then scale.”** because it describes a real risk-control behavior, not a vague feature.
- Kept **“总监改过的地方，下一轮不用再猜 / What the director corrected once should stay corrected.”** because it explains project memory through a familiar frustration.
- Rejected phrases such as “AI-powered creative revolution,” “10× consistency,” and “automated art direction.” The repository does not prove them and the director remains responsible for taste and approval.

## Keep

- One persistent production-board world rather than unrelated slide layouts.
- A real human studio moment at the opening.
- Semi-transparent oversized type used as atmosphere, behind the readable copy.
- Four visibly different art systems, each shown as production output rather than a detached mood image.
- Seven template crops spanning character, item, UI, VFX, match, puzzle, and tabletop work.
- Separate proof clips in the README so readers do not have to infer features from the hero film.

## Remaining risks

- Engine import and accessibility review remain project-level checks; this repository does not treat a visual review as either one.
- GitHub GIF playback is bandwidth-heavy; the committed still remains the reduced-motion and low-bandwidth fallback.
- The serif/sans system uses OS fonts, so line breaks can shift slightly across rendering environments. Release renders are fixed media and avoid that variation for README readers.

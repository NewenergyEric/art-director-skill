# 暮林守望 · V2 候选

一张可直接游玩的 1600×1000 林地防守地图。点击地面巡林；白天收集补给、点灯、建造；夜晚守住四轮双路径进攻。提灯和路灯会解除怪物暗甲，并提升光中防御塔的攻击节奏。

## 运行

使用 Node.js 执行 node server.mjs，打开输出的本地地址。可用 PORT 环境变量切换端口。无需 npm 安装、远程 API 或外部运行素材。

- index.html / v2.html：V2 新版入口。
- index-v1.html：保留的 V1 对照入口；旧冻结包仍在项目 artifacts。
- game-v2-config.js：地图路径、建造点、敌人职责、资源和波次。
- game-v2.js：确定性模拟、世界内界面、分层武器、实时光雾和事件。

## 操作

| 操作 | 作用 |
| --- | --- |
| 点击 / WASD / 方向键 | 移动守灯人；点击补给或灯台会走近后交互 |
| 点击遗迹，再点击设施 / 1、2、3 | 建造枝弩、松果臼炮、暮钟 |
| 点击已建塔 / U | 消耗灯籽、枝材与齿轮升级（暮钟免齿轮） |
| Q / E / R / X | 曙光、缠根陷阱、月露药、夜行符 |
| 空格 / TAB | 迎接夜晚 / 打开行囊 |
| H / P / F | 说明 / 暂停 / 全屏 |

## 本轮实际交付

- 28 件物品、环境及 UI 单件：12 件物品、12 件环境、4 件 UI；全数进入实际游戏或操作。
- 三类防御设施：固定底座、8 向枝弩与臼炮的瞄准/释放、独立摆铃。40 个真实生成状态源格，6 个静态单件。铃的14步播放序列复用8张姿态，不计为14帧新资产。
- 三套新增敌人各8帧：月蛾、孢囊、根甲卫；与既有荆背木灵构成4类职责。孢囊会分裂，臼炮不能攻击飞行单位。
- 守灯人11个生成部件、可编辑关节/关键帧JSON、12帧确定性烘焙。按走过的距离推进步态；烘焙帧不是12张独立生图。
- 新地图、独立手刻风格标题；游戏正文和数值统一 Noto Sans SC。标题可见文字“暮林守望”保留可编辑文本来源。

## 实际检查

evidence/v2/runtime/result.json：四夜、100击杀、12灯芯、零浏览器错误；真实点击建造、采集、添油及战斗通过。

edges-result.json：升级、暂停/说明冻结、全屏、失败、重开、暗甲及正常速度录制通过。1600×1000 Chrome 本次样本的帧间隔中位数16.7ms、95分位33.3ms；这不是所有设备性能承诺。

正常速度录像：evidence/v2/runtime/gameplay-v2-final-speed.mp4。截图、标准 Skill 客户端结果、原始回执和失败稿也在 evidence。

## 已知边界

本作是单地图四夜的可玩美术生产案例，所有新资产仍为候选、未获人类主美批准。武器每方向仅有瞄准/释放两个机械状态；角色与敌人没有完整四向转面，镜像会改变灯手在屏幕上的位置。根甲卫腿部运动较克制；守灯人最近帧播放有不超过约3.63px的子帧接触量化。未实现存档、移动设备专用界面或多关卡。

window.render_game_to_text() 返回语义状态；advanceTime(ms) 用固定步长推进，DuskGame.setRealtime(true) 恢复正常播放。测试需自行提供 Playwright 与 Chrome；环境变量见 evidence/v2/runtime/*.cjs。

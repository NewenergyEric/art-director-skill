# Nocturnal Restitution — case assets

This is the creator's original game case, published with their instruction on 2026-10-20.
The project uses the art-direction workflow to carry a restrained, illustrated gothic
language through character, environment, collectible, puzzle and UI production.

The three English screens are actual v30 runtime captures; v31 retained this artwork,
UI and gameplay. Isolated assets come from the matching v31 source. Sprite crops use
the game's registered coordinates, with no recoloring or generative repainting.
Character art is shown before runtime pose, scale and scene-light adjustments.

`provenance.json` records source hashes, exact crop rectangles, output hashes and bytes.
Screen captures are full-size WebP at quality 88. Component exports use quality 92;
their dimensions and alpha channel are preserved. Compression changes color pixels.
No game build, production drafts, tests, audio, private paths or credentials are included.
The visual comparison supports component consistency, not a claim of automatic visual
approval, complete hand-drawn animation or guaranteed performance on every device.

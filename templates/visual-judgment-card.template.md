# 图解判断卡：填写本卡解决的具体问题

按实际材料填写，删除不适用项。先给出一张可讨论的卡，不让主美填写空问卷；没有图像证据时明确为文字草案。

- 卡片 ID／版本、项目与冻结包版本：
- 规则／家族／资产及适用用途：
- 当前性质：既有规则解释 / proposed 新建议 / 有范围的例外
- 当前结论、观察者、日期与决定来源：未检查；不预填批准

| 图示与证据 | 要看哪里 | 可观察事实 | 支持什么；不支持什么 |
|---|---|---|---|
| 填实际图片相对路径；用 Markdown 图像嵌入，并保留完整图入口 | 区域、部件、帧或状态 | 描述所见，不把成因猜测写成事实 | 局部处理有效不等于整图批准 |
| 对照或反例的实际路径；若缺失就说明 | 同一问题的对应位置 | 保持可比条件 | 反例不作正向风格输入 |

- **使用与比较条件：** 显示位置、尺寸依据、背景、画布／主体缩放、裁切；哪些是试验条件？
- **判断与理由：** 当前规则或建议希望保住什么体验／功能？观察怎样支持它？
- **成因假设：** 尚需通过什么操作验证？
- **先后调整：** 先改什么，何时才需要第二种手段？
- **必须保留：** 身份、功能结构、主次、材料或状态中哪些不应随之改变？
- **复查：** 用什么视图／组合验证改动和保持项？
- **适用边界：** 哪些类别、材质、使用情境不能照用？
- **证据与未定项：** 技术实测、视觉自查、真实使用与负责人决定分别记录。
- **回写：** 关联源规则、参考／样板和决定；记录自身不赋予 approved 状态。

方法见[判断与返修指南](../references/visual-judgment.md)。复制到项目后更新所有相对链接；图例标注不进入正式素材。

# 连续动作制作与复核

本页处理“单张成立，连续播放却变形”。先沿用当前项目包；动作控制不另建人物身份或审美基线。

## 先确定不该变化的部分

把完整动作写成准备 → 发力/操作 → 接触或工具交接 → 收势，并标明时间、接触目标、持物手和道具归属。固定脸、发型、身体比例、服装结构、工具外形与尺度。衣服随关节产生的合理褶皱、透视缩短和遮挡变化不能简单当作像素漂移；需要结合结构判断。

先做一个可连续播放的代表动作。整身生成帧连续返修仍漂移时，定位原因并换方法，不继续用更多独立整身图、交叉淡化或快速切帧掩盖。可选择同母版局部动作、定向关键帧或实际可用的三维流程。每条路线写清运动范围和未解决能力：受限二维局部动作不能称为完整自然表演或真实三维蒙皮。

## 同母版也必须实际验证

明确底板、运动区域、重绘露出区域和前景遮挡各自的责任。先在中性姿势重组，再检查极限姿势和中间相位。身体不应残留旧手、旧工具或半透明轮廓；移动层不能夹带裤料、另一只手或背景碎片。

移除旧姿势时同时处理半透明边缘。用原 alpha 再做一次 destination-out 并不保证清空，可能留下 a×(1−a) 的残影。裁切上下文必须恢复；共享一个未恢复的 clip 会截掉随后追加的工具。检查完整运行合成图，文件尺寸和部件数量无法发现这类错误。

关节的局部变形区与手、工具的刚性区分开；不能让工具随皮肤权重伸长或变粗。网格检查中间相位的折叠、裂缝、三角接线和过度拉伸。保留必要的关节搭接与隐藏区域，不能靠大幅裁短素材隐藏接缝。生成底板若整体重新构图或缩放，应拒收，不能强行拉伸凑齐原坐标。

## 道具交接必须有连续的所有权

每一时刻明确道具由哪只手、桌面或支座持有。拾取和放下在同一坐标、同一角度交接；道具只出现一次，尺寸不能随着持有者改变。工具与手、工具与目标分别检查，不能只验证事件时间。油壶落台、引火杆取出、接触灯芯和回放等中间步骤需真实可见；缺少可达空间时先调整工作位置或姿势。

## 运行证据和返修记录

保留实际 1× 连续播放和完整正常交互流程；慢放、时间步进、并排预览作为诊断证据，分别标记。检查循环末帧→首帧、起步/结束→待机、暂停/恢复、存档续播，以及实际手机布局下的动作。审查时看同一动作的全过程，不用若干截图代替所有未观察区段。

固定区域的像素对照、接触误差、工具交接距离、文件哈希和相位覆盖只能支持判断，不能自动批准人体结构、运动自然度或所有场景。记录实际看过的区段、具体缺陷、返修与残留限制，不把检测通过写成用户批准。

分别统计生成调用、选用母版、底板/遮挡件、独立工具、绘制姿势和运行采样。程序计算出的 300 个相位仍可只使用一张母版；重复纹理的时间键不是 300 张新画帧。失败候选和未接入资源单列，保留输入、提示与对应版本。
